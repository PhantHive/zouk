## Overview

Z-muse is a Discord music bot that never reached wide release. Built as a public successor to [ISIER](https://github.com/PhantHive/ISIER-CLOSED-PROJECT), it was meant to bring music features to the Phearion bot network. Development stopped before a full release.

Z-muse is a property of **Phearion bot network**.

## Built With

- [Node.js](https://nodejs.org/en/)
